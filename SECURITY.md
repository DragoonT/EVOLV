# Security Policy

EVOLV is a self-modifying agent that runs shell commands and rewrites its own
files on your machine. That is the product. Please read `README.md → Security`
before using it with sensitive data.

## Reporting

Found a sandbox escape, path traversal, or anything the agent can do that it
shouldn't? Email **dxn1.0day@gmail.com** directly — please don't open a public
issue for exploit details. Discord @dxn1_ai works too.
