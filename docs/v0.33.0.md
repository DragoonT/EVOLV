# v0.33.0 — Field Notes

Two changes define this release: the workspace stops wearing a full DNA render
as wallpaper, and a release stops being something we believe in — it becomes
something the pipeline proves.

## A quieter body

The `dna-ambient` iframe is gone. It was a complete genome visualisation running
behind every conversation at 72% opacity, and it cost more than it gave.

In its place is `ui/ambient.js`, a small canvas field: slow drifting particles,
faint filaments between neighbours, and a palette read from `--accent` so it
changes clothes with the appearance playground.

- Density scales with the viewport and is capped at 76 nodes.
- Device pixel ratio is capped at 2; the canvas is resized once per debounced
  frame, not per particle.
- Animation pauses when the tab is hidden and resumes on return.
- `prefers-reduced-motion` produces one still frame and no animation loop.
- The accent is re-read when the theme or appearance changes.

The shell around it is rebuilt in the same pass: deep moss surfaces, signal-lime
accent, glass on the sidebar/header/composer, a gradient hero, softer tool cards
and full paper-theme parity. No element IDs, event handlers, hot-swap hooks or
organ mounts changed — the organism can still rewrite this skin live.

## A release that verifies itself

Packaging now lives in one reusable workflow, `_package.yml`, called by both CI
(on every pull request) and the release workflow (on tags).

1. **Build** all six supported targets with the version injected at link time.
2. **Verify the manifest** with `scripts/verify-artifacts.sh`: exactly the six
   expected binaries, no stale extras, the Linux binary reports the release
   version, and checksums are generated and checked.
3. **Boot the artifact** with `scripts/smoke.sh` against a throwaway `HOME`:
   health, metrics, the UI, the ambient asset, swarm routes, a full
   `.evolvpack` export/inspect/import round-trip, cross-origin 403,
   DNS-rebinding 421, and a clean SIGTERM drain.
4. **Publish** only that verified distribution, adding an SBOM, regenerating
   checksums over the complete set, and attesting provenance.

A tag cannot ship a binary that lies about its version: `release.yml` compares
the tag and the source `internal/workspace.Version` before anything is built.

The pipeline also gained five-run nightly stress, a protocol fuzzing job,
macOS/Windows unit gates and shellcheck on the release scripts.

## Verification

```bash
make check                 # gofmt, vet, tests
make smoke                 # boot the built binary and probe it end to end
node --check assets/ui/ambient.js
```

On CI, the `package / release dry-run` job runs the same packaging path a tag
would run, including the boot smoke, so packaging regressions fail on the pull
request rather than during a release.

## Upgrading

Nothing to migrate. The workspace format is unchanged; existing components,
organs, plans, runs and snapshots keep working. The old `genome.html?ambient=1`
mode remains available for anyone who wants to open the genome view directly.
